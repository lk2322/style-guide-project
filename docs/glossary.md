# Глоссарий

Термины «Сальдо» и то, как мы их пишем. Слова из колонки «Не пишем» ловит линтер (`scripts/check_style.py`, список в `scripts/terms.yml`).

## Термины продукта

<!-- style-check: off -->

| Термин | Что значит | Не пишем |
|---|---|---|
| счёт | Место, где лежат деньги пользователя: карта, наличные, вклад, брокерский счёт | кошелёк, аккаунт (в значении счёта) |
| операция | Любое движение денег: доход, расход или перевод | транзакция |
| доход | Операция, которая увеличивает баланс счёта | поступление, приход |
| расход | Операция, которая уменьшает баланс счёта | трата, списание (кроме текста о банковской выписке) |
| перевод | Операция между двумя счетами пользователя. Не считается ни доходом, ни расходом | трансфер |
| категория | Группа операций: «Продукты», «Транспорт», «Зарплата» | тег, рубрика |
| баланс | Сколько денег на счёте сейчас | остаток, сальдо |
| бюджет | Лимит расходов по категории на месяц | план |
| портфель | Все ценные бумаги и валюта на брокерских счетах пользователя | инвестиции (как название раздела) |
| актив | Позиция в портфеле: акция, облигация, фонд, валюта | бумага (в интерфейсе), инструмент |
| сделка | Покупка или продажа актива | трейд, операция (для покупки и продажи бумаг) |
| выплата | Дивиденд, купон или погашение облигации | начисление |
| доходность | Изменение стоимости портфеля с учётом выплат, в процентах за период | профит, прибыльность |

## Сокращения

При первом упоминании на странице сокращение расшифровываем.

| Сокращение | Расшифровка |
|---|---|
| ИИС | индивидуальный инвестиционный счёт |
| ОФЗ | облигация федерального займа |
| НКД | накопленный купонный доход |
| ISIN | международный идентификационный код ценной бумаги |
| API | программный интерфейс приложения |

## Как добавить термин

Откройте пул-реквест, который меняет эту страницу и `scripts/terms.yml` одновременно. В описании объясните, где возникла путаница.
