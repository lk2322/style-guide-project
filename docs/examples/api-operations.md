# `POST /operations`

Создаёт операцию на счёте пользователя: доход, расход или перевод.

!!! note "Пример написан по руководству"
    Страница составлена по [шаблону метода API](../doc-templates/api-method.md) и проверяет его на реальном методе бэкенда «Сальдо».

## Авторизация

Нужен токен доступа пользователя в заголовке `Authorization: Bearer <токен>`. Операцию можно создать только на своём счёте.

## Параметры

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `account_id` | `string` (UUID) | да | Счёт, к которому относится операция |
| `type` | `string` | да | Тип операции: `income`, `expense` или `transfer` |
| `amount` | `integer` | да | Сумма в копейках, больше нуля. Знак задаёт `type`, а не сама сумма |
| `currency` | `string` | да | Код валюты по ISO 4217: `RUB`, `USD` |
| `category_id` | `string` (UUID) | нет | Категория. Для `transfer` не передаётся |
| `target_account_id` | `string` (UUID) | только для `transfer` | Счёт, на который переводятся деньги |
| `occurred_at` | `string` | да | Дата и время операции в ISO 8601 с часовым поясом |
| `comment` | `string` | нет | Комментарий пользователя, до 500 символов |

## Пример запроса

```http
POST /api/v1/operations HTTP/1.1
Authorization: Bearer eyJhbGciOi...
Content-Type: application/json
```

```json
{
  "account_id": "6f1c2a7e-3b4d-4c8e-9a10-2b5f7d9e1c33",
  "type": "expense",
  "amount": 125000,
  "currency": "RUB",
  "category_id": "0c9e4b2a-7d1f-4e6a-8b3c-5a2d9f1e7b44",
  "occurred_at": "2026-10-09T13:45:00+03:00",
  "comment": "Продукты на неделю"
}
```

## Пример ответа

```json
{
  "id": "a3d5f7b9-1c2e-4f60-8a9b-0d1e2f3a4b55",
  "account_id": "6f1c2a7e-3b4d-4c8e-9a10-2b5f7d9e1c33",
  "type": "expense",
  "amount": 125000,
  "currency": "RUB",
  "balance_after": 4875000,
  "created_at": "2026-10-09T13:45:02+03:00"
}
```

Поле `balance_after` — баланс счёта в копейках после операции. В примере это 48 750 ₽.

## Коды ответа

| Код | Когда возвращается |
|---:|---|
| 201 | Операция создана |
| 400 | Не передано обязательное поле, `amount` меньше или равен нулю, для `transfer` нет `target_account_id` |
| 401 | Токен не передан или истёк |
| 404 | Счёт или категория не найдены либо принадлежат другому пользователю |
| 422 | Валюта операции не совпадает с валютой счёта |
