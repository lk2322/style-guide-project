# Как писать об интерфейсе

Большая часть справки — это путь по экранам приложения. Если названия в тексте не совпадают с экраном, пользователь теряется на втором шаге.

## Названия элементов

**Обязательно.**

- Название кнопки, вкладки или раздела пишем точно как в интерфейсе, в кавычках-ёлочках: «Добавить операцию», вкладка «Расходы».
- Если у кнопки нет подписи, а только значок, описываем значок и выделяем его полужирным: нажмите **+**, нажмите значок **⋮**.
- Тип элемента («кнопка», «поле», «переключатель») пишем, только если без него непонятно: «включите переключатель „Учитывать в бюджете“».

## Глаголы действий

**Обязательно.** Для одного действия всегда используем один глагол.

<!-- style-check: off -->

| Действие | Глагол | Не пишем |
|---|---|---|
| Касание кнопки или пункта | нажмите | кликните, тапните, щёлкните |
| Выбор из списка | выберите | укажите, отметьте |
| Ввод текста или суммы | введите | впишите, вбейте |
| Переход в раздел | откройте | зайдите, перейдите в |
| Включение опции | включите | активируйте, поставьте галочку |
| Свайп по строке | смахните влево | свайпните |

## Путь по экранам

**Рекомендуется.** Если до нужного места больше двух переходов, даём путь через знак **→**:

> Откройте «Профиль» → «Настройки» → «Валюта по умолчанию».

Путь пишем один раз в начале шага, дальше — только действие.

## Скриншоты

**Рекомендуется.**

- Скриншот добавляем, если элемент трудно найти по описанию. На каждый шаг скриншот не нужен.
- Снимаем на светлой теме, на демо-данных. Реальные суммы, номера счетов и карт не показываем.
- На скриншоте обводим нужный элемент рамкой цвета акцента. Стрелки и текст поверх не рисуем.
- Обязательно пишем альтернативный текст: что на картинке и зачем она здесь.

## Платформы

**Обязательно.** Если на Android и iOS шаги отличаются, разводим их по вкладкам или пишем отдельный шаг для каждой платформы. Не пишем «нажмите назад» без уточнения: на iOS нет системной кнопки «Назад».
