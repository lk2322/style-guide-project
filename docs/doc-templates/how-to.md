# Шаблон: инструкция

Для страниц справки, которые ведут пользователя к одному результату. Скопируйте блок ниже в новый файл и замените текст в угловых скобках.

````markdown
# <Задача пользователя в инфинитиве: «Добавить покупку облигации»>

<Одно-два предложения: что получится в итоге и когда это нужно.>

## Перед началом

<Что должно быть готово. Если ничего не нужно — удалите раздел.>

- <условие>

## Шаги

1. Откройте «<раздел>».
2. Нажмите «<кнопка>».
3. <действие>

<Что пользователь увидит после последнего шага.>

## Если что-то пошло не так

<Одна-три частые проблемы в формате «симптом — что делать».>

## Смотрите также

- [<название связанной страницы>](<путь>.md)
````

## Чек-лист перед пул-реквестом

- [ ] Заголовок отвечает на вопрос «что я сделаю?».
- [ ] Каждый шаг начинается с глагола в повелительном наклонении.
- [ ] Названия кнопок совпадают с интерфейсом текущей версии.
- [ ] Суммы и даты оформлены по разделу [«Числа, деньги и даты»](../style/numbers.md).
- [ ] У каждого скриншота есть альтернативный текст.
