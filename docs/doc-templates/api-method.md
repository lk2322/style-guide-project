# Шаблон: метод API

Для страниц в `docs/api` репозитория бэкенда. Одна страница — один метод.

````markdown
# `<МЕТОД> <путь>`

<Что делает метод, одним предложением.>

## Авторизация

<Какой токен нужен. Если метод публичный, так и напишите.>

## Параметры

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `<имя>` | `<string, integer, boolean>` | да | <описание; для сумм: в копейках> |

## Пример запроса

```http
<МЕТОД> /api/v1/<путь> HTTP/1.1
Authorization: Bearer <токен>
Content-Type: application/json
```

```json
{
  "<поле>": "<значение>"
}
```

## Пример ответа

```json
{
  "<поле>": "<значение>"
}
```

## Коды ответа

| Код | Когда возвращается |
|---:|---|
| 200 | <успех> |
| 400 | <какие поля проверяются> |
| 401 | Токен не передан или истёк |
````
